누가 · 어떤 에이전트(Claude Code / Codex)로 · 무엇을 하고 있는지 한눈에 보입니다. 설치만 하면 같은 망의 다른 PC를 **서버 없이** 찾아 모두의 에이전트가 한 사무실에 모입니다.

> [pixel-agents](https://github.com/pixel-agents-hq/pixel-agents)(MIT)의 포크입니다. 원작은 내 PC의 Claude Code 에이전트만 보여 주고, 이 포크는 LAN 공유 · Codex 지원 · 설치 파일을 더하는 대신 에이전트 실행 · 터미널 · VS Code 확장을 뺐습니다. 보기만 하는 앱이고, 에이전트는 쓰던 CLI·데스크톱 앱에서 그대로 실행합니다.

## 설치

1. [Releases](https://github.com/YOOJUNGYU/pixel-office-lan/releases/latest)에서 받습니다: Windows `PixelOffice-<버전>-Windows.exe`, Mac(Apple 칩·Intel) `PixelOffice-<버전>-Mac.pkg`. Node 는 들어 있어 따로 설치할 것이 없습니다.
2. 코드 서명이 없어 경고가 뜹니다.
   - **Windows**: "Windows의 PC 보호" → **추가 정보** → **실행** → 사용자 계정 컨트롤 **예**
   - **Mac**: 막히면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**. 방화벽이 켜져 있으면 "들어오는 연결 허용"
3. 브라우저에 사무실이 열리면 캐릭터와 색을 고릅니다(닉네임은 선택). 이어서 사용법 투어가 나옵니다.

- 로그인할 때 자동으로 켜집니다(**설정 → 로그인할 때 자동 실행**). 끄려면 트레이 아이콘 → **Pixel Office 종료** 또는 **설정 → 완전 종료**.
- 다시 열기: 트레이 → **Pixel Office 열기**, Windows 바탕화면·시작 메뉴 바로가기, Mac **응용 프로그램**, 또는 `http://localhost:47801`.
- 업데이트는 자동입니다(아래 [그 밖에](#그-밖에)).

다른 PC가 안 보일 때, 제거 방법은 **[설치 안내](docs/설치-안내.md)**를 보세요. 회사 보안 프로그램이 막으면 IT 담당자에게 예외 등록을 요청하세요.

## 사용법

### 방 = 하는 일

에이전트는 하는 일이 3초 이상 이어지면 그 방으로 걸어가 빈자리에 앉습니다. 방 명패에 마우스를 올리면 설명과 그 방의 에이전트가 나옵니다. 명패의 `에이전트 N` 은 그 방의 에이전트 수(서브에이전트·셸 포함)이고, 대기실 명패에는 없습니다.

| 방        | 이런 일을 할 때                                                             |
| --------- | --------------------------------------------------------------------------- |
| 🖥️ 코딩실 | 파일 수정 (Claude `Edit`/`Write`, Codex `apply_patch`)                      |
| 📚 자료실 | 파일 읽기, 코드·웹 검색 (Codex 의 `rg`·`cat`·`git log` 같은 읽기 명령 포함) |
| 🗄️ 서버실 | 명령 실행 (`Bash`, Codex 셸), 백그라운드 셸                                 |
| 🛋️ 대기실 | 입력·승인 대기, 작업 끝남 — 그 PC 의 사람 캐릭터에 합쳐짐                   |

- **이름표**: 한 줄로 **MAIN** / **SUB** / **SHELL** 배지, `#번호`, 닉네임(없으면 PC 계정). 왼쪽 위 **이름표·말풍선 숨기기**로 에이전트 이름표와 말풍선을 한꺼번에 숨깁니다(기본은 보임). 사람 캐릭터의 이름표는 늘 보이고, 배경·글자색은 각자 프로필에서 고릅니다(내 것은 노란 테두리).
- **말풍선**: 일하는 에이전트 머리 위에 Claude / Codex 배지와 지금 하는 일이 나오고, 마우스를 올리면 전체 내용이 보입니다. 머리 위 **빨간 !** = 확인을 기다림(대기실에 합쳐진 에이전트면 사람 캐릭터 위에).
- **서브에이전트·셸**은 부모와 같은 방이면 손을 잡고 다니고, 다른 방이면 따로 있습니다.
- **지도**: 드래그로 이동, 휠로 확대·축소(왼쪽 위 + / −).

![말풍선](docs/images/hover-ko.png)

### 오피스 (맨 위 전환 버튼)

탭마다 지금 접속한 인원이 나옵니다(나 포함, 개인용일 때는 나를 뺀 인원).

- 🌐 **공개 오피스**(기본): 같은 망에서 앱을 설치한 모두.
- 🔒 **팀 오피스**: 초대 코드(`PO2-…`)를 아는 사람끼리만. **설정 → 오피스**에서 만들기(코드 복사해 전달) · 코드로 참여 · 나가기. ⚠️ 팀 오피스에 하나라도 들어가 있으면 **공개 오피스에서 완전히 빠집니다**(보지도, 보이지도 않음).
- 🏠 **개인용**: 다른 PC로 아무것도 보내지 않는 혼자 쓰는 작은 사무실. 다른 PC 의 신호는 듣기만 해서 접속 인원만 셉니다. 팀 멤버십은 남아 있어 코드 없이 돌아갑니다.

### 내 캐릭터와 채팅

- 에이전트와 별개로 사람마다 캐릭터가 하나 있습니다. **방향키**로 어느 방이든 걷고(벽·가구는 못 지나감), 대기실 의자에는 앉을 수 있습니다. 위치는 다시 켜도 기억됩니다.
- 아래 가운데 **채팅창**에 쓰고 **Enter** → 내 캐릭터 머리 위 말풍선. 한 사람에 하나라 새로 쓰면 바뀌고, **×** 로 지웁니다. 대화 기록은 없습니다. 100자, 2초에 한 번까지.
- 단축키: 아무것도 선택되지 않았을 때 **Space+Enter** = 채팅창, 채팅창에서 **Esc** = 방향키로 복귀.

### 접속자 패널과 PC 알림

- 오른쪽 **접속자 패널**: 이 오피스에 있는 사람 전부(에이전트 없어도). 이름을 누르면 그 사람의 에이전트로 이동.
- **PC 알림**(Windows·Mac, 창을 닫아도 트레이가 있으면 옴. 설정에서 각각 끄기):
  - **접속·퇴장**: 공개 오피스에서 누가 들어오거나 나갈 때.
  - **내 에이전트**: 내 Claude·Codex 가 응답을 기다리거나 작업을 마쳤을 때(세션 제목·프로젝트 폴더 표시, 이 PC 에서만).

### 그 밖에

- **프로필**: 캐릭터(사람 6종 또는 펫 Claudio · Gitcat), 색, 닉네임, 내 캐릭터 이름표의 배경·글자색. 이름은 항상 PC 계정 이름이 먼저이고 바꿀 수 없습니다. 닉네임은 겹칠 수 없습니다(나중에 정한 쪽에 `· a1b2` 같은 구분 표시가 붙음).
- **언어·테마**: 한국어/English, 다크/라이트/시스템을 보는 사람마다 따로. 왼쪽 위 해/달 버튼으로 바로 전환.
- **레이아웃 편집**: 바닥(방 클릭 한 번에 방 전체), 벽, 가구, 바깥 배경. 네 방의 영역과 사무실 크기는 고정입니다(기본 사무실 83×54, 위: 코딩실 · 서버실, 아래: 자료실 · 대기실).
  - 편집한 내용은 **[저장]** 을 눌러야 저장되고, 그 전에는 이 화면에만 있습니다. 버튼: **[초기화]**(기본 배치로, 저장해야 적용) · **[실행 취소]**(Ctrl+Z) · **[다시 실행]**(Ctrl+Y) · **[저장]**(저장·공유하고 닫기) · **[취소]**(바꾼 내용을 모두 버리고 닫기, Esc 도 같음).
  - **공개·팀 오피스**: 누구나 편집할 수 있고, 저장하면 그 오피스에 접속한 모두에게 공유됩니다(공개 = 같은 망, 팀 = 팀원끼리 암호화). 동시에 고치면 **마지막에 저장한 배치**가 남습니다. 1.0.13 이하 PC 에는 공유되지 않고, 예전에 PC 마다 저장한 배치(`layout.json`)는 쓰지 않습니다(가져오기로 다시 올릴 수 있음).
  - **🏠 개인용**: 이 PC 에만 저장됩니다.
  - 기본 배치로 되돌리기: 편집기의 **[초기화]** 후 **[저장]**. 파일로 남기기: **설정 → 레이아웃 내보내기 / 가져오기**.
- **앱으로 설치(PWA)**: Edge·Chrome 에서 오른쪽 위 설치 창 → 탭 없는 앱 창. 서버가 꺼진 채 앱을 열면 **[시작]** 으로 켤 수 있습니다.
- **자동 업데이트**: 켤 때와 6시간마다 확인해 조용히 받아 다시 시작하고, 열린 창도 새 버전으로 바뀝니다. 새 버전이 시작에 실패하면 이전 버전으로 돌아갑니다. 끌 수 없습니다. Node 가 바뀌는 릴리스만 오른쪽 위 **업데이트** 버튼으로 설치 파일을 받습니다.
- **사용법 다시 보기**: 설정에서 투어를 다시 봅니다.

## 보안과 개인정보

- 다른 PC와는 **상태만** 주고받습니다(읽기 전용). 남의 터미널·에이전트·설정에는 접근할 수 없고, 화면은 내 PC 브라우저에서만 열립니다.
- PC 사이 통신은 모두 **암호화**됩니다. 공개 오피스는 PC 쌍마다 X25519 로 키를 합의해 AES-256-GCM, 팀 오피스는 초대 코드에서 만든 키로 AES-256-GCM. 코드는 네트워크로 나가지 않고, 한 번 본 PC의 키가 바뀌면 무시합니다(사칭 방지).
- **항상**: 파일 경로, 사용자 이름, IP·호스트명, URL 경로, 토큰처럼 보이는 문자열, AI 답변 내용은 PC 밖으로 나가지 않습니다. 명령은 프로그램 이름만. PC 계정 이름은 이름표라서 항상 보입니다.
- **내 작업 내용 숨기기**(기본 꺼짐): 다른 사람에게는 내 에이전트가 어느 방에 있는지, 어떤 AI인지, MAIN·SUB·SHELL 종류, 응답 대기(!) 여부만 보이고 작업 내용은 보이지 않습니다.
- Claude Code·Codex 설정은 건드리지 않고 대화 기록 파일만 읽습니다.

## 동작 방식

```
 [내 PC]                                         [동료 PC]
 Claude / Codex 대화 기록 ─▶ 리포터 ─┐        ┌─ 리포터 ◀─ 대화 기록
  (~/.claude, ~/.codex, WSL)          │ 암호화 │
                                      ├◀──────▶┤   1초마다 UDP 로 상태 공유 (서버 없음)
 브라우저 ◀── WebSocket ── 로컬 서버 ◀┘        └▶ 로컬 서버 ── WebSocket ──▶ 브라우저
 (앱 창) http://localhost:47801                        http://localhost:47801 (앱 창)
```

- 리포터는 `~/.claude/projects`, `~/.codex/sessions`(Windows 에서는 실행 중인 WSL 배포판 것도)에서 최근 30분 안에 바뀐 세션을 읽습니다. 닫힌 Claude 세션은 몇 초 안에(프로세스를 확인할 수 없으면 30분 뒤), 끝난 Codex 세션은 10분 뒤에 사라집니다.
- 5초 동안 소식이 없는 PC는 사라집니다. 레이아웃은 네트워크로 보내지 않습니다.
- 데이터는 `~/.pixel-office/` 에만 저장합니다(키·코드가 든 파일은 0600).

| 포트      | 용도                                            |
| --------- | ----------------------------------------------- |
| UDP 47800 | PC끼리 상태 주고받기 (브로드캐스트 + 지정한 IP) |
| TCP 47801 | 브라우저 화면 (`127.0.0.1` 전용)                |

## 알려진 한계

- 브로드캐스트는 같은 서브넷 안에서만 갑니다. 층·VLAN 이 달라 안 보이면 **설정 → 내 프로필 → 고급: 자동으로 안 보일 때**에 상대 IP를 넣으세요.
- 공개 오피스는 앱을 설치한 사람의 참여를 막지 못합니다. 참여자를 정하려면 팀 오피스를 쓰세요.
- Codex 는 승인 요청을 기록에 남기지 않아, ❗ 는 Codex 가 질문할 때만 뜹니다.
- 민감 정보 가림이 명령·검색어 속에 직접 적은 비밀번호까지 모두 잡지는 못할 수 있습니다.
- 버전이 섞여 있으면 예전 PC에 일부가 안 보입니다(0.4.x: 에이전트가 아주 많은 PC·펫, 1.0.0 이하: 사람 캐릭터·채팅, 1.0.13 이하: 공유 레이아웃). 모두 업데이트하세요.
- Mac 알림은 "Script Editor" 이름으로 보일 수 있습니다. Linux·WSL 에는 트레이·알림이 없습니다.

## 개발

```bash
npm install
npm run build              # dist/ — cli.js에 의존성까지 번들 (node_modules 없이 실행)
node dist/cli.js --open    # http://localhost:47801
npm test                   # server + webview (Vitest)
npm run check-types && npm run lint
```

- 구조와 규칙: [CLAUDE.md](CLAUDE.md). 설계와 구현 계획: [docs/superpowers/](docs/superpowers/).
- **릴리스**: `package.json` 의 `version` 을 올리고 `v<버전>` 태그를 push 하면 GitHub Actions 가 Windows·Mac 설치 파일과 자동 업데이트용 번들을 Release 에 올립니다. 태그에 `-` 가 있으면 사전 릴리스이고, 정식 릴리스는 이전 릴리스를 지웁니다.
