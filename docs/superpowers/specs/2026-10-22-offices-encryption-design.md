# 오피스(공개/팀) · 통신 암호화 · PWA — 설계 (v0.2.0)

작성일: 2026-10-22 · 선행: `2026-10-21-pixel-office-lan-design.md` (v0.1.0)

> 원격 구경 제거 (v0.4.0, 사용자 결정) — 아래 "원격 구경" 항목은 더 이상 유효하지 않다. 화면은 내 PC 브라우저(loopback)에만 제공한다.

## 1. 왜

v0.1.0 은 PC 간 상태를 **평문 UDP 브로드캐스트**로 보낸다. 같은 망의 누구나 엿보고 가짜 캐릭터를 끼워 넣을 수 있다. HTTPS(사설 인증서)는 이 경로를 보호하지 못하고 경고만 늘려 쓰지 않는다. 사용자는 설정 없이 자동으로 암호화되길 원하고, 원하는 사람끼리만 모이는 "초대받은 사람만 들어오는 방"도 원한다.

## 2. 결정 사항 (사용자 승인)

| 항목              | 결정                                                                                                                                                                                                                  |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 🌐 공개 오피스    | 기본. 같은 망의 앱 설치자 모두. PC 마다 X25519 키 쌍 자동 생성, 서로 발견하면 쌍별 키 합의 → AES-256-GCM 으로 암호화해 **상대에게만 유니캐스트**. 브로드캐스트에는 공개키만.                                          |
| 🔒 팀 오피스      | "만들기" → **초대 코드** 생성(복사해 공유). 코드에서 유도한 키로 암호화, 코드를 아는 사람끼리만 보인다. 여러 개 동시 가입 가능. 화면 위에서 오피스 전환.                                                              |
| 소속 규칙         | 팀 오피스에 하나라도 들어가 있으면 **공개 오피스에서 완전히 빠진다**(보내지도 보지도 않음 — 몰래 보기 방지). 공개로 돌아가려면 팀에서 모두 나간다.                                                                    |
| 사칭 감지         | 한 번 본 PC 의 공개키를 기억(TOFU). 같은 PC id 로 다른 키가 오면 무시하고 경고.                                                                                                                                       |
| PWA               | `http://localhost:47801` 을 앱으로 설치 가능(manifest + service worker). Windows 바로가기/시작 메뉴는 Edge 앱 창(`--app=`)으로 연다(Edge 없으면 기본 브라우저).                                                       |
| 원격 구경         | **기본 끔**: 내 PC 가 아닌 브라우저의 접속을 거부. 설정에서 켜면 "같은 망에 평문(HTTP)으로 보입니다" 경고. 켜져 있어도 **공개 오피스만** 보여 주며, 내가 팀 오피스에 있으면 원격 구경자에게는 아무것도 보이지 않는다. |
| 호환              | v0.1.0 과 통신하지 않는다(평문 v1 패킷은 무시). 업데이트로 모두 0.2.0 으로 올린다.                                                                                                                                    |
| 사설 인증서 HTTPS | 하지 않음 (위 이유).                                                                                                                                                                                                  |

## 3. 안티 목표

- 팀 오피스의 내용(닉네임·작업)이 공개 오피스나 원격 구경자에게 새는 것.
- 팀 코드 비밀이 네트워크로 나가는 것(코드는 사람이 메신저로 공유할 뿐, 앱은 코드의 해시 태그만 보낸다).
- 사용자가 아무 설정을 안 했을 때 평문이 나가는 것.
- 코드 입력을 강제하는 것(공개 오피스는 설정 없이 동작).

## 4. 한계 (명시)

- 공개 오피스는 **엿보기**를 막지만, 앱을 설치한(또는 프로토콜을 흉내 낸) 사람의 참여는 막지 못한다. 참여를 제한하려면 팀 오피스를 쓴다.
- 팀 오피스 보안은 코드 비밀의 기밀성에 달려 있다. 코드가 새면 새 팀을 만들어 옮긴다.
